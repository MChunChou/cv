## 本人負責工作與成果
- 使用 ECharts 動態產生圖表，支援使用者自訂維度組合分析。
- 設計廠區／課／部門三維資料結構，作為資料篩選核心模型。
- 開發依 Server 設定自動生成欄位與順序的可配置動態表單。

- 建立使用者偏好設定，以 localStorage 儲存設定並提供匯出／匯入。

- 實作單台與多台設備資訊頁面及條件式動態切換。
- 建立新增、編輯、刪除流程及 Text、Date、Dropdown 可重用篩選元件。
- 建立設備安裝階段關聯流程圖。

## 系統功能範圍
- **Tool Schedule：**安裝狀態、階段及快速篩選；表單預設值、我的最愛、自動儲存、下載、重新整理及多選刪除。
- **Task Schedule：**檢視 MoveIn、T0 等安裝階段細節，支援 KeyStage 批次調整日期及選擇是否連動後續日期。
- **Tool Information：**依欄位定義提供 Selector、Finder、FreeFinder、Text、Date 等輸入，支援欄位連動、語系、copy/create as new 及離頁警告。
- **My Schedule：**最多六個自訂表單、Tool List 條件、Tool Information、task/checklist、上傳／下載及表格內修改。
- **FAC Plan：**以 qaData、SP1、SP2 呈現安裝計畫關聯，顯示 plan／actual 日期、詳細資料、狀態提示及上游／下游警示。
- **Dashboard、Setting、Report、Manual Support、User Guide：**提供排程統計圖表、依設定產生搜尋條件、指定廠區報表、支援表單及操作教學連結。
- **History Query：**tmp 筆記僅列頁面名稱，功能細節待補。
