## 專案概述
開發 Web-based CNC HMI 系統，取代原有 Java 版本。工作包含控制器操作介面、CNC 程式編輯與模擬、檔案傳輸及前後端架構演進。

## 本人工作與成果
- 使用 Web 架構取代原有 Java HMI，提升跨平台能力與維護效率（依專案履歷表記載）。
- 前端初期使用 YUI Mojito，後續重構為 React。
- 後端初期使用 Node.js，後續重構為 Rust。
- 開發 CNC 操作面板與控制選單。
- 開發 CNC 程式編輯頁面與模擬功能。
- 使用 PEG.js 轉換 CNC 程式碼為 Forth 指令。
- 實作 CNC 設定檔案上傳／下載。
- 使用 Three.js 建立視覺模擬系統。

## 技術與架構
- **前端：**YUI Mojito、ReactJS、Three.js、PEG.js。
- **後端：**Node.js、Express、Rust。
- **應用：**CNC 狀態資訊顯示、控制選單、程式編輯、3D 路徑模擬及檔案傳輸。
